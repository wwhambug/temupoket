# TEMUPOKET

픽셀풍 포켓로그 패러디 배틀 게임. 순수 HTML/CSS/JavaScript, 빌드 과정 없음.

## 플레이

`index.html`을 브라우저에서 열거나, 이 저장소를 Vercel 등에 정적 사이트로 배포하면 바로 플레이할 수 있다.

## 구성

- `index.html` — 타이틀 / 난이도 선택 / 전투원 선택 / 배틀 화면
- `css/style.css` — 전체 스타일
- `js/data.js` — 전투원 7종 데이터·타입 상성
- `js/battle.js` — 전투 로직 (데미지·크리티컬·AI)
- `js/main.js` — 화면 전환·연승 모드·전적
- `js/music.js` — WebAudio 칩튠 BGM (타이틀/배틀)
- `assets/` — 전투원 앞/뒤 스프라이트 14종 + 배틀 배경

## 게임 요소

- 전투원 7종: 지우(인간), 핵탄두(핵), 양념치킨(음식), 와이파이공유기(전기), 전기장판(전기), 로또용지(인간), 불닭볶음면(음식)
- 타입 상성: 인간 → 전기 → 음식 → 핵 → 인간
- 크리티컬 히트 (1/16 확률, 1.5배)
- 난이도 3종 (쉬움/보통/어려움)
- 연승 모드 (HP 이어받기, 최고 연승 기록)
- localStorage 전적 기록 (승/패/도주)
- BGM 음소거 저장/복원, 도움말 모달
